# Portfolio Website

This is my personal portfolio website hosted using GitHub Pages.

## Live Website
https://puneethx47.github.io/portfolio/

## Technologies Used
- HTML, CSS, and vanilla JavaScript
- Native Web Animations API and Intersection Observer
- CounterAPI for the public portfolio-visit total

## Portfolio features

- Privacy-safe, in-page résumé viewer with no phone number or download control
- Cross-platform animations with reduced-motion support and no animation-library CDN dependency
- A shared visit counter that increments once per browser; local previews do not increment it
